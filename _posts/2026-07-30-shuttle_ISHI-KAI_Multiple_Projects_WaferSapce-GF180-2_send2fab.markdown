## [Wafer.Sapce GF180 Run 2](https://www.crowdsupply.com/wafer-space/gf180mcu-run-2/) がファブ（工場）への提出が完了！！！
こちらの「[Wafer.Sapce GF180 Run 2 への投稿完了！！！](https://ishi-kai.org/waferspace/shuttle/gf180/2026/07/13/shuttle_ISHI-KAI_Multiple_Projects_WaferSapce-GF180-2_submitted.html)」でお伝えした[Wafer.Sapce GF180 Run 2](https://www.crowdsupply.com/wafer-space/gf180mcu-run-2/)への緊急投稿ですが、無事に採択されて、工場に送付されたとのことです。  


  ![みんなのデザイン](https://github.com/ishi-kai/ISHI-KAI_Multiple_Projects_WaferSapce-GF180-2/raw/main/images/chip_image_klayout.png?raw=true)  
  ![みんなのデザインとラベル](https://github.com/ishi-kai/ISHI-KAI_Multiple_Projects_WaferSapce-GF180-2/raw/main/images/chip_image_members.png?raw=true)  


### [Wafer.Sapce GF180 Run 2の投稿サイト](https://github.com/wafer-space/ws-run2)
[Wafer.Sapce GF180 Run 2の投稿サイト](https://github.com/wafer-space/ws-run2)も公開されています。  
ISHI会のものは、中央段の右から2番目の黄色い領域です。  

    ![最終面付](https://raw.githubusercontent.com/wafer-space/ws-run2/main/images/G802.svg)


ということで、以前から言っていますが、無料枠は突然湧くので、普段からいろいろと作っておくといざというときに製造チャンスがやってきます。  
みなさまも、普段からぜひとも回路やレイアウトに励んでいただければと思います。  


### [Wafer.Sapce](https://wafer.space/)とは？
[GoogleでOpenMPW](https://developers.google.com/silicon?hl=ja)のボスであったTimが、Googleを離れて2025年4月くらいに[Wafer.Sapce](https://wafer.space/)を立ち上げました。そして、4か月くらいの準備期間を経て[GF180をベースとしたチップ作成のクラファン](https://www.crowdsupply.com/wafer-space/gf180mcu-run-1/)がスタートしました。
